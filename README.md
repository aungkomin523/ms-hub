# PlanPulse — AI-Powered Project Planning & Milestone Studio

A modern project planning and timeline collaboration SaaS application built with **React**, **React Bootstrap**, and **SCSS**. PlanPulse helps teams turn project ideas into organized schedules, visual milestones, and actionable tasks with integrated AI insights.

---

## Features

- **Interactive Project Timeline Studio:** Three-column workspace featuring a milestone sidebar, an interactive monthly calendar view, and a real-time detail inspector.
- **Dynamic Calendar View:** Uniform grid layout tracking milestones by target due dates, supporting month-to-month navigation and in-cell scrollable items.
- **Projects Dashboard:** Overview of all workspaces with progress tracking, search and status filters (All, In Progress, Completed), and KPI summary metrics.
- **Team Collaboration & Access Control:** Share and invite teammates via email with granular permissions (Owner, Editor, Viewer).
- **AI Project Planning & Insights:** Scaffolding for automatic milestone generation, scope breakdowns, and schedule conflict detection.
- **SaaS Subscription & Trial Architecture:** Designed around a 30-day full-access trial model converting into a simple £5/month Pro subscription tier.
- **Dark & Light Mode:** Theme toggle with an embedded animated slider, powered by Bootstrap color mode tokens.

---

## Tech Stack

- **Frontend:** React, React Router v6
- **UI Framework:** React Bootstrap, Bootstrap 5.3+
- **Styling:** SCSS, Custom CSS variables, Linear SVG gradients
- **Icons:** Custom inline SVGs
